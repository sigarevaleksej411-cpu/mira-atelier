# Mira Atelier — новый проект ИИ-компаньона

Mira Atelier — полностью отдельная версия Миры со светлым журнальным интерфейсом, собственной векторной иллюстрацией, историей разговоров и облачными ответами через Gemini. Она не загружает локальную языковую модель, поэтому браузеру телефона не нужно держать сотни мегабайт весов в памяти.

## Что внутри

- `public/` — фронтенд сайта и PWA: HTML, CSS, JavaScript, манифест, service worker и иконки.
- `netlify/functions/chat.mjs` — серверная функция, которая безопасно обращается к Gemini и передаёт ответ потоком.
- `netlify.toml` — настройки публикации и расположение функции.

Модель по умолчанию — `gemini-3.5-flash-lite` (низкая задержка и экономичный режим). В настройках можно выбрать `gemini-3.8-flash` для более сложных задач. Доступность модели, цены и квоты определяются Google AI Studio / Gemini API.

## Важно: почему нельзя просто перетащить ZIP на Netlify Drop

Обычная публикация перетаскиванием ZIP размещает статические файлы, но для этого проекта ещё нужна серверная функция. Поэтому публикуй проект через репозиторий GitHub, подключённый к Netlify, либо через Netlify CLI. Иначе страница откроется, но чат не найдёт функцию `/.netlify/functions/chat`.

## Публикация через GitHub и Netlify

1. Распакуй архив.
2. Создай репозиторий на GitHub. Для личного проекта лучше выбрать **Private**.
3. Загрузи в корень репозитория всё содержимое папки проекта, сохранив структуру:
   - `netlify.toml`
   - `public/` (внутри `index.html`, `manifest.webmanifest`, `sw.js`, `assets/`)
   - `netlify/functions/chat.mjs`
   - `.gitignore`
4. На Netlify создай новый проект через **Add new project → Import an existing project** и подключи этот репозиторий.
5. Build command оставь пустой. Publish directory должен быть `public`. Функция берётся из `netlify/functions` по `netlify.toml`.
6. До первого использования добавь переменные в настройки проекта Netlify → **Environment variables**:
   - `GEMINI_API_KEY` — API-ключ из Google AI Studio: https://aistudio.google.com/apikey
   - `MIRA_ACCESS_CODE` — личный длинный пароль (не менее 16 символов). Придумай уникальный; не используй пароль от других аккаунтов.
7. После добавления переменных сделай новый deploy/redeploy.
8. Открой новый HTTPS-адрес сайта. Открой **Настройки**, вставь значение `MIRA_ACCESS_CODE` в поле «Код доступа к твоему сайту» и сохрани настройки.
9. Отправь короткое тестовое сообщение.
10. Чтобы установить на Android: открой HTTPS-сайт в Chrome → меню `⋮` → «Установить приложение» или «Добавить на главный экран».

**Не записывай `GEMINI_API_KEY` в файлы проекта, HTML, JavaScript, ZIP или репозиторий GitHub.** Ключ читается только серверной функцией из переменных Netlify. `MIRA_ACCESS_CODE` также должен задаваться в переменных окружения, а не в исходниках.

## Можно ли разработать без компьютера?

Да, но загрузка папок в GitHub с телефона иногда неудобна. Сохрани структуру каталогов в файловом менеджере; если мобильная версия GitHub не позволяет сохранить вложенные папки, проще открыть в браузере режим «Версия для ПК» либо выполнить импорт репозитория с компьютера.

## История и приватность

- История чатов и заметки памяти сохраняются только в локальном хранилище браузера на этом устройстве.
- История не синхронизируется между телефонами и удалится при очистке данных сайта. Экспорт истории в этой версии не реализован.
- Для генерации выбранные сообщения, текущие заметки памяти и системная инструкция отправляются в Gemini через серверную функцию. Не отправляй пароли, секреты или чувствительные данные.
- Код доступа помогает ограничить доступ к прокси, но сам по себе не является полноценной системой аккаунтов. Не публикуй пароль доступа и установи лимиты/оповещения на API-аккаунте.
- PWA кэширует оболочку интерфейса, но генерация ответов требует интернета и работающей облачной функции.

## Локальная проверка фронтенда

Статическую часть можно посмотреть из папки проекта:

```bash
python -m http.server 8000 --directory public
```

Затем открыть `http://127.0.0.1:8000`. Но без Netlify Functions и заданных серверных переменных чат не сможет обращаться к модели. Для проверки функции локально потребуется Netlify CLI (`netlify dev`).
